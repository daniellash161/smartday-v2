Everything that shapes your day, in one place

Instead of opening five apps every morning, SmartDay connects to the sources you already use and reads them for you.

  • Google Calendar

    Today's and upcoming events, automatically sorted into categories like study, work and personal.

  • Apple Calendar

    Import any ICS file to bring in events from iCloud or other calendar apps.

  • Gmail

    Surfaces important emails with read-only access. SmartDay can never send or delete anything.

  • Card statements

    Upload a PDF statement to spot subscriptions, standing orders, installments and unusual charges.

  • Tasks and alerts

    Suggested tasks and smart alerts generated from your events, prioritized by what's due soonest.

How a PDF statement becomes an insight

The most technical part of SmartDay: a document pipeline that handles both digital and scanned statements, without a server.

  1. Upload

    You drop in a PDF statement from an Israeli credit-card provider.

  2. Read the text layer

    PDF.js extracts native text first, which is fast and exact for digital files.

  3. Fall back to OCR

    Scanned pages are rendered to a canvas and read with Tesseract.js running as WebAssembly.

  4. Detect and parse

    The provider is identified and only transaction-relevant lines are kept.

  5. Classify

    Rules flag subscriptions, standing orders, installments and unusual charges.

Privacy by design. The file never leaves your browser. Raw text, card numbers and IDs are not stored; only the processed insights are kept.

Under the hood

A fully client-side React app, designed and built end to end.

  • React 18
  • TypeScript
  • Vite
  • PDF.js
  • Tesseract.js (WASM)
  • Google Calendar API
  • Gmail API
  • ICS parsing
  • Vercel

  • No backend, on purpose

    All parsing, OCR and analysis run in the browser. Personal data like statements and email stays on the user's device.

  • Least-privilege integrations

    Gmail uses the read-only scope, so the app can surface messages but has no way to change them.

  • Rule-based, explainable logic

    Priorities, alerts and daily insights come from transparent rules over your events and tasks, so every suggestion can be traced to its cause.

  • Built for Hebrew

    A right-to-left interface from the ground up, with light and dark themes and a guided onboarding flow.
